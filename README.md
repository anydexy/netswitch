# NetSwitch

Программа для Windows и macOS, которая переключает способы обхода блокировок: DNS для обхода гео-блоков, Cloudflare WARP и zapret, а также ускоряет Telegram через TG WS Proxy. Интерфейс сделан в стиле Apple: светлая, тёмная или системная тема и два вида — расширенный и компактный (узкое окно, как у телефона, только главное). Переключатели темы и вида — в правом верхнем углу.

## Возможности

- **DNS для обхода гео-блоков:** Comss, GeoHide, DNS-AI, MALW, Xbox DNS.
- **Обычные DNS:** Cloudflare, Google, Control D, ControlD Uncensored, OpenDNS, NextDNS, Verisign, Neustar, AdGuard, Quad9, Comodo Secure.
  - Все DNS собраны на одной вкладке «DNS»: карточки по 4 в ряд с сортировкой по задержке, по обходу гео-блоков или по названию.
  - У каждого способа видно пинг, время ответа DNS, есть ли интернет и какую страну видят сайты (ChatGPT, Claude).
  - Из всех серверов сервиса выбираются два самых быстрых и прописываются во все активные адаптеры (на macOS — во все подключённые сетевые службы), для IPv4 и IPv6. По желанию можно включить DoH (Windows 11).
- **Исключения DNS:** выбранные сайты с поддоменами (по умолчанию figma.com) всегда открываются через обычный DNS (8.8.8.8, 1.1.1.1), даже когда подключён DNS для обхода. В Windows сделано через таблицу политик разрешения имён (NRPT), в macOS — файлами `/etc/resolver`. В браузере «Безопасный DNS» должен быть выключен.
- **Cloudflare WARP:** управляет официальным клиентом через `warp-cli`.
- **Zapret:**
  - Windows — сборка [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) (winws + WinDivert), можно установить службой Windows;
  - macOS — `tpws` из оригинального [bol-van/zapret](https://github.com/bol-van/zapret): прозрачный прокси, на который трафик к сайтам (TCP 80/443) направляют правила PF. UDP (QUIC, голос Discord) на macOS не обходится;
  - скачивание последней версии и проверка обновлений, запуск и остановка, тест всех стратегий с выбором лучшей.
- **TG WS Proxy** (сборка [Flowseal/tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy)) — локальный MTProto-прокси, который ускоряет Telegram Desktop:
  - скачивание последней версии с проверкой контрольной суммы и проверка обновлений;
  - запуск и остановка, перезапуск при падении;
  - подключение Telegram в один клик («Открыть в Telegram») или копирование ссылки;
  - если TG WS Proxy уже был запущен отдельно, NetSwitch переносит его настройки и ключ, и Telegram перенастраивать не нужно.
- **«Самый быстрый»:** проверяет все способы и подключает лучший.
- **Авто-режим:** если текущий способ перестал работать, программа сама переключается на рабочий.
- **Обновления:** при запуске и раз в 12 часов программа проверяет последний релиз на GitHub. Если есть новая версия, появляется окно с описанием, а в авто-режиме (по умолчанию) архив для своей системы скачивается, проверяется по контрольной сумме, ставится, и программа перезапускается — открытое окно переподключается само. Вручную — «Настройки → Обновления → Проверить обновления».
- Автозапуск: в Windows — через Планировщик (с правами администратора, без окна UAC, значок в трее), в macOS — заданием launchd при загрузке (без запроса пароля).

## Установка

### Windows

1. Скачайте `NetSwitch-windows.zip` со страницы **Releases**.
2. Распакуйте в отдельную папку, например `C:\NetSwitch`.
3. Запустите `NetSwitch.exe` и подтвердите запрос прав администратора.

Если Защитник Windows удалит `winws.exe` или WinDivert, добавьте папку программы в исключения.

### macOS (11 Big Sur и новее, Intel и Apple Silicon)

1. Скачайте `NetSwitch-mac.zip` со страницы **Releases** и распакуйте.
2. Перетащите `NetSwitch.app` в «Программы».
3. Программа не подписана сертификатом Apple, поэтому при первом запуске macOS её не откроет («повреждена» или «не удаётся проверить разработчика»). Один раз выполните в Терминале:
   ```
   xattr -dr com.apple.quarantine /Applications/NetSwitch.app
   ```
4. Запустите NetSwitch и введите пароль администратора — он нужен, чтобы менять DNS и запускать zapret.

Окно открывается в Chrome, Edge или Brave в режиме приложения, если они установлены, иначе — в браузере по умолчанию. Значка в строке меню нет: если закрыть окно, программа продолжит работать, а окно снова откроется при запуске NetSwitch. Выход — в «Настройках».

## Сборка из исходников

Нужен Go 1.24 или новее, сторонние зависимости не нужны.

Windows:

```
GOOS=windows GOARCH=amd64 go build -trimpath -ldflags "-H=windowsgui -s -w" -o NetSwitch.exe .
```

На Windows можно запустить `build.bat`.

macOS — универсальная программа (Intel + Apple Silicon), `NetSwitch.app` и архив `NetSwitch-mac.zip`. Собирается на любой системе, Xcode не нужен:

```
go run ./tools/macapp -version 1.4.0 -out dist
```

## Проверка

GitHub Actions (.github/workflows): тесты на Windows и macOS; на настоящем macOS программа запускается от root и проверяет смену DNS, исключения DNS, zapret (tpws + PF), тест стратегий и TG WS Proxy (.github/scripts/mac-smoke.sh). Workflow «Update e2e» собирает старую версию и проверяет обновление до последнего релиза на Windows и macOS.

## Как устроено

- Бэкенд написан на Go. Интерфейс — встроенная HTML-страница (`ui/index.html`). Её показывает локальный сервер на `127.0.0.1` с одноразовым токеном, а открывается она в окне браузера в режиме приложения.
- Код, который зависит от системы, лежит в файлах `*_windows.go` и `*_darwin.go`. Разбор вывода утилит macOS (`networksetup`, `scutil`, `ping`, `ps`) — в `macparse.go`, его тесты запускаются на любой системе.
- Windows: настройки хранятся в `netswitch.json`, журнал — в `netswitch.log`, zapret лежит в папке `zapret\`, TG WS Proxy — в папке `tgws\`. Всё это находится рядом с exe. TG WS Proxy работает в портативном режиме: его настройки и ключ хранятся в `tgws\TgWsProxy_data`, а не в `%APPDATA%`. Остановка штатная, как «Выход» в меню его значка в трее.
- macOS: всё то же лежит в `~/Library/Application Support/NetSwitch`, внутрь `NetSwitch.app` программа ничего не пишет. После ввода пароля NetSwitch перезапускает себя от root без окна, а окно, ссылки и уведомления открывает от имени пользователя. TG WS Proxy ставится из официального `.dmg` и работает от имени пользователя с настройками в `~/Library/Application Support/TgWsProxy`. Правила PF для zapret ставятся в ветку `com.apple/netswitch`, `/etc/pf.conf` не меняется; при выходе из программы и после перезагрузки правил нет.
