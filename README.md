# NetSwitch

Программа для Windows и macOS, которая сама делает так, чтобы нужные сайты и программы открывались. Для каждого сайта и программы NetSwitch подбирает рабочий и быстрый способ обхода блокировок, следит, чтобы всё работало, и переключает, если что-то перестало открываться. Всё работает одновременно: у каждого сайта свой путь.

**[Скачать последнюю версию →](https://github.com/anydexy/netswitch/releases/latest)**

## Способы, из которых NetSwitch выбирает

- **Напрямую** — сайт и так открывается, NetSwitch его не трогает.
- **DNS для обхода гео-блоков** — Comss, GeoHide и другие: сайты, закрытые для вашей страны (ChatGPT, Gemini, Claude). Можно добавить свой DNS.
- **zapret** — обход замедления и блокировок провайдера прямо на компьютере (YouTube, Discord).
- **Cloudflare WARP** — бесплатный туннель Cloudflare для того, что не открылось иначе (Instagram, игры).
- **VPN** (Windows) — ваша подписка или VPN-программа (Happ, Hiddify, v2rayN и другие). Только для того, что не открылось другими способами или открывается слишком медленно.
- **TG WS Proxy** — ускоряет Telegram Desktop.

## Что умеет

- Пошаговая настройка при первом запуске; к любому шагу можно вернуться.
- Сайты и программы (Windows): способ подбирается сам, его можно выбрать и вручную — «Авто», «Сначала …» или «Только …».
- Подсказки (Windows): если сайт в браузере не открывается, а в обход открывается, — уведомление; нажали, и сайт добавился с подходящим способом.
- Списки zapret без ручной правки файлов.
- Светлая и тёмная тема, компактный вид, значок в трее, автозапуск, автообновление.

## Установка

**Windows 10 и 11.** Скачайте `NetSwitch-windows.zip`, распакуйте в отдельную папку (например, `C:\NetSwitch`), запустите `NetSwitch.exe` и подтвердите запрос прав администратора — они нужны, чтобы менять DNS и запускать zapret. Если Защитник Windows удалит `winws.exe` или WinDivert, добавьте папку программы в исключения: это обычная реакция антивируса на драйвер перехвата трафика.

**macOS 11 и новее** (Intel и Apple Silicon). Откройте `NetSwitch-mac.dmg` и перетащите NetSwitch в «Программы». Программа не подписана сертификатом Apple, поэтому один раз выполните в Терминале:
```
xattr -dr com.apple.quarantine /Applications/NetSwitch.app
```
VPN, выбор программ и подсказки пока работают только в Windows.

В браузере выключите «Безопасный DNS» (или выберите «Текущий поставщик»), иначе браузер обходит DNS для обхода.

## Открытые компоненты

NetSwitch использует открытые проекты — спасибо их авторам. Компоненты, которые скачиваются при работе, берутся с их официальных страниц и проверяются по контрольной сумме.

- [zapret](https://github.com/bol-van/zapret) и сборка [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube)
- [sing-box](https://github.com/SagerNet/sing-box) (GPL-3.0) — скачивается отдельно, без изменений
- [TG WS Proxy](https://github.com/Flowseal/tg-ws-proxy)
- [amneziawg-go](https://github.com/amnezia-vpn/amneziawg-go) (MIT) и [Wintun](https://www.wintun.net/)
- [go-webview2](https://github.com/wailsapp/go-webview2) (MIT)
- [bash-warp-generator](https://github.com/ImMALWARE/bash-warp-generator) — как регистрируется устройство WARP
