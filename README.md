# NetSwitch

Программа для Windows, которая переключает способы обхода блокировок: DNS для обхода гео-блоков, Cloudflare WARP и zapret, а также ускоряет Telegram через TG WS Proxy. Интерфейс сделан в стиле Apple, есть светлая и тёмная темы.

## Возможности

- **DNS для обхода гео-блоков:** Comss, GeoHide, DNS-AI, MALW, Xbox DNS.
- **Обычные DNS:** Cloudflare, Google, ControlD, AdGuard, Quad9.
  - У каждого способа видно пинг, время ответа DNS, есть ли интернет и какую страну видят сайты (ChatGPT, Claude).
  - Из всех серверов сервиса выбираются два самых быстрых и прописываются во все активные адаптеры, для IPv4 и IPv6. По желанию можно включить DoH (Windows 11).
- **Cloudflare WARP:** управляет официальным клиентом через `warp-cli`.
- **Zapret** (сборка [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube)):
  - скачивание последней версии и проверка обновлений;
  - запуск и остановка;
  - установка как служба Windows;
  - тест всех стратегий с выбором лучшей.
- **TG WS Proxy** (сборка [Flowseal/tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy)) — локальный MTProto-прокси, который ускоряет Telegram Desktop:
  - скачивание последней версии с проверкой контрольной суммы и проверка обновлений;
  - запуск и остановка, перезапуск при падении;
  - подключение Telegram в один клик («Открыть в Telegram») или копирование ссылки;
  - если TG WS Proxy уже был запущен отдельно, NetSwitch переносит его настройки и ключ, и Telegram перенастраивать не нужно.
- **«Самый быстрый»:** проверяет все способы и подключает лучший.
- **Авто-режим:** если текущий способ перестал работать, программа сама переключается на рабочий.
- Значок в трее и автозапуск вместе с Windows (через Планировщик, с правами администратора и без окна UAC).

## Установка

1. Скачайте `NetSwitch.zip` со страницы **Releases**.
2. Распакуйте в отдельную папку, например `C:\NetSwitch`.
3. Запустите `NetSwitch.exe` и подтвердите запрос прав администратора.

Если Защитник Windows удалит `winws.exe` или WinDivert, добавьте папку программы в исключения.

## Сборка из исходников

Нужен Go 1.22 или новее, сторонние зависимости не нужны.

```
GOOS=windows GOARCH=amd64 go build -trimpath -ldflags "-H=windowsgui -s -w" -o NetSwitch.exe .
```

На Windows можно запустить `build.bat`.

## Как устроено

- Бэкенд написан на Go. Интерфейс — встроенная HTML-страница (`ui/index.html`). Её показывает локальный сервер на `127.0.0.1` с одноразовым токеном, а открывается она в окне Edge в режиме приложения.
- Настройки хранятся в `netswitch.json`, журнал — в `netswitch.log`, zapret лежит в папке `zapret\`, TG WS Proxy — в папке `tgws\`. Всё это находится рядом с exe.
- TG WS Proxy работает в портативном режиме: его настройки и ключ хранятся в `tgws\TgWsProxy_data`, а не в `%APPDATA%`. Остановка штатная, как «Выход» в меню его значка в трее.
